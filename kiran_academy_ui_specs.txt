1. Prototype Scope
The prototype represents the proposed enterprise user interface only. It must be navigable using static HTML 
links and should contain realistic hardcoded sample data so that the screens look like an operational 
recruitment application.

No Java, Python, JDBC, Flask, Django, Servlet, JSP, API, or database connection is required in the prototype.

All data displayed in tables and cards may be hardcoded in HTML.

Navigation between pages should work using relative HTML links.

Forms do not need to save data; buttons may remain non-functional unless navigation is useful.

The visual design should be consistent across all pages.

The same prototype document is to be used by both Java and Python students.






Minimum package cannot exceed maximum package.



Candidate does not meet the eligibility criteria.

